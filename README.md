# StockPearl

StockPearl is a free, chart-first way to explore the fundamentals of US-listed companies. Revenue, margins, earnings, cash flow and balance sheet trends are shown as clean, interactive charts, with a simple screener to filter companies.

It's built on SEC EDGAR data and original company filings, for long-term investors and curious learners who want to understand a business, not chase tips.
